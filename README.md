# WallPipe AR — 配管可視化シミュレーター

企業・製品に依存しない、架空の配管網を観察するWeb実験デモです。実際の壁内配管を検出する機能ではありません。

## v0.4 の操作

- 画面をタップ、または「新しい配管を透視」で、その場の**架空の配管ネットワークを新たに生成**します。接続位置、経路の長さ、枝分かれはランダムに変化します。同じ場所を再びタップしても同じ配管に戻るわけではありません。
- 透視表示はタップ位置から段階的に広がります。動きを減らすOS設定では即時表示します。
- 3つのバルブをタップして開閉できます。配管網を抵抗ネットワークとして解き、出口への流れを簡易再計算します。代替経路があればその経路に流れが回ります。**実際の圧力、流量、漏水などを予測する精密な流体解析ではありません。**
- 「壁」「床」「天井」を手動選択できます。「傾きで自動切替」は端末の姿勢センサが利用できる端末のみ機能します。向きの推定であって、実際の壁や床の形状認識ではありません。
- 「現在の階」は手動指定です。「高度を取得」は位置情報の同意を得て高度と精度を参考表示するだけです。GPS高度から階数は断定しません。取得値をアプリのサーバーには送信しません。ブラウザやOSによる測位処理は別です。
- 給水・空調・工場の設備表示、流体表示のON/OFF、透過度・倍率調整、カメラ映像への手動重ね合わせ、キーボード操作に対応しています。

## 3D / AR の制約

- 3D / ARモードは**固定サンプルのGLB配管模型**です。2Dのランダム生成、ネットワーク計算、タップ位置とは**連動しません**。
- [model-viewer](https://modelviewer.dev/) 4.4.0 を使用しています。端末によりWebXR、Scene Viewer、AR Quick Lookを呼び出します。
- マーカー不要のAR配置は対応端末のOS機能に依存し、壁面固定やiPhoneでの実機動作は未検証です。
- カメラ合成は通常の2Dオーバーレイで、移動しても配管が壁の同じ場所に固定されるわけではありません。

## 安全・公開範囲

- 実際の配管位置・建物図面・製品仕様は含みません。
- 高度はユーザーが明示的にボタンを押した場合だけ取得を試みます。階数は取得しません。
- カメラ映像や測位データをアプリ独自のバックエンドへ送信するコードはありません。
- GitHub Pagesの公開サイトは通常、誰でも閲覧できます。

## 開発者向け

- メイン画面: `index.html`（HTML/CSS/Canvas/JavaScript）
- 3Dデモ: `assets/*.glb`（24種類の固定サンプル）
- 再生成: `tools/generate_models.py`
- 外部モジュール: model-viewerのみ。企業固有データや有料APIは使いません。

GitHub Pages URL: https://mill-miya.github.io/wallpipe-ar/

設計学習・展示のための模式モデルであり、設備の設計・保守・安全評価に利用しないでください。
